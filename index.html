Projects

Tejamkor — automated price comparison for Uzbek electronics

Python · Playwright · BeautifulSoup · Telegram Bot API · live channel

Texnomart, Mediapark and Asaxiy rarely agree on price. The bot checks all three and publishes the comparison to a Telegram channel on its own.

  • One adapter per store, each written against what that store actually exposes — an internal JSON endpoint, a product-filter API, and server-rendered cards with the data hidden in attributes.
  • A matching function scores model tier, storage, RAM, network and colour across four languages to decide whether two listings are the same product, and blocks publishing when they aren't.
  • Appliance names share no vocabulary between stores, so it joins on manufacturer model codes instead: 368 codes harvested, 69 refrigerators found in two or more stores.

MMAT — retrieval-augmented support chatbot

Python · LangChain · OpenAI · FAISS · Telegram Bot API · pandas · team project

A Telegram assistant for laptops, mice and headsets, answering specification, warranty and delivery questions without a support agent on shift.

  • Knowledge base built from manuals and support documents with LangChain, embedded with OpenAI and stored in a FAISS index.
  • Two-stage routing for cost and latency: regex resolves the repetitive questions, only the remainder reaches the model. Off-topic questions are refused rather than answered.

Uzbek-language order and FAQ bot for small retailers

Python · Telegram Bot API

Small retailers in Uzbekistan take orders in Telegram messages and answer the same questions all day. The bot does both, in Uzbek — built, deployed and debugged end to end for a non-technical shop owner, alongside Power BI reporting.

Data mining & analysis

Customer churn prediction for a telecom operator

Orange · Telco Customer Churn dataset

Three classifiers compared under 5-fold cross-validation to find which subscribers were about to leave. Reported and presented in Korean.

  • Logistic regression led at AUC 0.845, against 0.811 for the neural network and 0.609 for the decision tree.
  • Contract type was the strongest predictor, which pointed the recommendation at contract structure rather than discounting.

Consumer segmentation for a direct-mail campaign

CRISA bath soap panel · 600 households · K-Means, Random Forest

Segmenting a purchase panel to find which households justified the cost of a mailing.

  • K-Means at k = 5 produced five distinct segments; a Random Forest then assigned new households to them.
  • Recommended Segment 4 as the target, argued for a marketing audience rather than a technical one.

Delivery performance and customer satisfaction in Brazilian e-commerce

SPSS · Orange · Kaggle Brazilian E-Commerce dataset

How much of a customer's satisfaction is decided by delivery?

  • Merged five relational tables into one order-level dataset, deriving delivery time, delivery delay and order value so each row was a complete order.
  • Delivery time correlated with review score at r = −0.334 (p < 0.001) and was the strongest regression predictor at β = −0.267 — though the model explained only 12% of the variation, so most of satisfaction sits elsewhere.
  • Orange K-means reached the same conclusion independently, splitting orders into fast, mid and delayed clusters with matching satisfaction profiles.
